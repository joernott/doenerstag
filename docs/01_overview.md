# 01 Overview

doenerstag is a web application for ordering food for a group of 1 to n people. It has a persistent database of restaurants with their logo, contact information and menu. Food orders can be created for a specific date/time on the dynamically and are made available publicly. Users can add themselves to the order and pick one or more menu items and add clickable andf freetext modifications for them. There is a summary page that shows a compact list of orders.

This application does not collect payments or place orders with restaurants- It just helps organizing food orders.
